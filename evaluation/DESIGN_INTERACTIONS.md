# 3D option, group movement and large-project Design loading — 2026-10-28

Lens now has three independent choices: Impact map, Layers and 3D. The flat map remains the default. The optional 3D explorer uses XYZ positions, perspective projection, camera orbit/pan/zoom and screen-facing labels with collision avoidance. It shares the graph, inference filter, source evidence and display limit with the other maps. No browser or GPU runtime is added.

3D node coordinates are fixed. Clicking selects evidence; dragging a node or its label does not move it. Camera orbit, pan and zoom remain available. This restriction is specific to the 3D Lens; Design cards retain group movement. Mouse-event regression checks cover both node/label drags and camera orbit.

Design group dragging previously moved Qt's selected cards visually, but committed only the grabbed card's coordinates to the draft. The undo command rebuilt the scene with the other cards' old coordinates. A drag release now commits every moved card in one transaction. Unselected cards stay in place, connectors follow the moved endpoints, and one Undo/Redo restores/reapplies the whole group. Multi-selection is retained after the commit and after Undo/Redo. This applies to the shared canvas used by code structure and feature flows.

The reported Windows hang was reproduced while loading the backend-navigation Design report: 9,806 declarations and 2,898 module dependency rows. Repeated full declaration/path scans for each package blocked the UI thread for approximately 25.96 seconds. A prepared per-report scope index, cached pure path classification and reuse of the report's already extracted design relationships reduced the same report-population measurement to approximately 0.22 seconds on this development machine. Subsequent tab switches measured approximately 0.01–0.02 seconds. These measurements cover GUI report population, not repository analysis or a benchmark on the presentation laptop.

The scope index is transient data on a dict subclass; it is not duplicated into exported JSON. Each new source review builds its own index in the existing worker. The declarations/dependencies preview limits remain unchanged.

Verification: the complete automated suite passed, 215 tests with 12 existing Rope deprecation warnings. New checks use actual Qt press/move/release events for group dragging, single-card dragging, retained selection, connector updates, single-step Undo/Redo, repeated group movement and design-file roundtrip. A 10,000-declaration / 500-package regression rejects per-group source-path rescans and confirms exported JSON omits the transient cache. Native checks cover 3D projection/orbit/reset, shared evidence and group movement. Source profiling read the user's repository without executing or editing it.
