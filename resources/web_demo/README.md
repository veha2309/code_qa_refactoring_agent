# Web sample

Use **Project: Open web sample** in the command palette. Select `invoiceTotal` in the Lens to follow direct and transitive test evidence and the React component reference.

Edit the calculation, save, then **Follow changes** to inspect the diff. Choose **Run linked tests** and trust this sample to execute its Node test file. All tests in the selected file run, including the unrelated shipping test. Node.js 20 or later must already be installed; no npm installation is needed for these tests.

`Invoice.tsx` is a static React analysis example. React is declared to demonstrate framework detection; the app does not download dependencies or launch a React app. The sample has no Next.js routing, browser test or TypeScript runtime.
