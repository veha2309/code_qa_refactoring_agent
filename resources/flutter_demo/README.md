# Flutter sample

Open **Project: Open Flutter sample** from Ctrl+Shift+P. Focus `AuthCard` in the Lens to follow its references through both screen classes and `DemoApp` into the widget tests. Flutter `build` relationships are explicitly labeled inferences.

Indexing, search, diffs, local model completion and checked AI proposals work without Flutter installed. Formatting needs `dart.exe` from an existing SDK on PATH. Test execution needs a prepared Flutter SDK and this project's dependencies; the app does not run `pub get` or download SDK artifacts.

To prepare this editable sample yourself, run `flutter pub get` in its directory before working offline. Then use **Run linked tests** and explicitly trust the sample. All tests in the selected test file run. No emulator is required for these widget tests. The app does not launch an emulator or run `flutter run`.
